# OStimAnchorAlign

**OStim Standalone**（7.5以降）用のSKSEアドオンです。アニメーションの基準身長と身長が違うアクター同士でも、
**身長を変えずに**シーンの位置合わせを補正します。

何を合わせるかは、そのステージで行われている内容（OStimのアクション情報）で決まります。

| アクション | 合わせる部位 |
|---|---|
| 挿入（膣・アナル） | 陰茎 ↔ 膣・骨盤 |
| キス | 顔 ↔ 顔 |
| フェラ・クンニ・リム | 顔 ↔ 股間 |
| パイズリ・尻ズリ・素股・手コキ・足コキ | その部位 ↔ 陰茎 |
| … | `SKSE/Plugins/OStimAnchorAlign/anchors.json` を参照 |

## 仕組み

- ルールごとに2つの基準ボーンの位置を測り、「2人とも身長1.0（アニメ制作時の基準）だったらどこにあるか」と比べます。
  差は身長差の分だけなので、アニメ本来のポーズや距離感、隙間はそのまま残ります。
- 1つのステージに複数のアクションがあるとき（3P、キスしながらの挿入など）は、重み付き最小二乗法でアクターごとの移動量を求めます。
- 移動はスケルトンの `NPC` ノードに見た目だけかけます。アクター本体の座標は動かさないので、OStimの位置固定とは競合しません。
  NiOverrideのヒール補正など、他のMODが書き込んだ値も残したまま上乗せします。
- ハイヒールの高さも身長差として補正します（`bHeelAware`）。多くの立ちシーンではOStimがヒールの持ち上げを外すため、靴が床に埋まります。アクターが自分の足で立っている間は、その持ち上げを戻します（`bRestoreHeels`）。
- 標準設定（`iMode=1`）では、ステージ開始後1.5秒間の補正量を平均して固定します。`iMode=0` では毎フレーム追従します。
- 床に立っている（膝立ち・寝そべりも含む）アクターは上下に動かしません。背の高い側を下げる必要があるときは、足を床に固定したまま膝を曲げて腰を下げます（脚のIK、`[LegIK]`）。
- 抱え上げなど、片方が持ち上げられている体位では、持ち上げられている側だけを上下に動かします。
- 膝立ち（正座も含む）の側が低すぎるときは、膝と足を床に固定したまま太ももを起こして腰を上げます。寝そべっている人は上下に動かしません。
- **腕のIK**（`[ArmIK]`）：胸や尻を揉む、頭を撫でる、つかむ、手マン・手コキなど、手で触る動作では、腕を曲げて手のひらを相手の部位まで届かせます。手の向きはアニメのまま保ち、手首が不自然に折れないよう肘の位置と上半身の傾きで調整します。対象は `anchors.json` の `handTargets` と `handActions` で決まります。

## 必要なもの

- Skyrim SE 1.5.97 / AE 1.6.x
- SKSE64
- Address Library for SKSE Plugins
- OStim Standalone 7.5以降
- XPMSE、または互換のスケルトン（標準のボーンの名前を使うもの）
- 任意：SKSE Menu Framework（ゲーム内の設定画面を使う場合）
- OStimの **「Disable Scaling」はオンのまま** にしてください（身長差を残すためのMODです）。

## 設定

**ゲーム内メニュー（任意）**：[SKSE Menu Framework](https://www.nexusmods.com/skyrimspecialedition/mods/120352) を入れていれば、Modコントロールパネル →「OStim Anchor Align」から全項目をその場で変更できます。一時停止キーはキーを押して登録でき、表示言語は英語と日本語から選べます。変更はINIに保存されます。

**一時停止キー**：標準は **左Shift + Pause** で、すべての補正を一時停止・再開します。一時停止中や補正するものがないときは、スケルトンに一切触れないので、他のポーズ編集ツールと併用できます。

**胸に触れる手**：`[ArmIK]` の `fBreastUp` / `fBreastForward` で、手の位置を上下・前後にずらせます（標準は上に3）。アニメの想定より胸が大きい体型では、値を大きくしてください。

`SKSE/Plugins/OStimAnchorAlign.ini` はシーンが切り替わるたびに読み直されるので、ゲーム中に編集できます。
ログは `Documents/My Games/Skyrim Special Edition/SKSE/OStimAnchorAlign.log` です。

## 困ったときは

- 不具合を報告するときは、ログと、問題のシーン・ステージ名を添えてください。`[Debug]` の `bVerboseLog = 1` で詳しいログが出ます。
- 0.5.0から、毎フレームの処理をゲームのメインループで実行しています。お使いのゲームのバージョンでこれが原因の問題が出る場合は、`[Debug]` の `iUpdateHook = 0` で以前の方式（0.4.0まで）に戻せます。メインループのフックを入れられなかった場合も、自動で以前の方式に戻ります。

## 互換性

- **PPA - Procedural Penis Animations**：テスト済みで、併用をおすすめします。このMODが腰同士を近づけ、PPAが最後に陰茎を曲げて合わせます。
- **GT-Soft Body / CBPC / SMP の物理**：テスト済みです。物理は補正後のポーズについていきます。
- **Fabulous Poser** などのポーズ編集MOD：0.5.0からすべての処理をメインスレッドで決まった順番に実行するので、震えや元に戻される問題は直っているはずです（Fabulous Poser では未確認）。一時停止キーで補正を止めることもできます。
- **OStim Alignment Heel Fix**：0.5.0からは不要です。両方を使うとヒールの分が二重に補正される可能性があります。使い続ける場合は `bHeelAware = 0` と `bRestoreHeels = 0` にしてください。
- **SexLab**：非対応です。このMODはOStimのステージごとのアクション情報を土台にしていて、SexLabにはその情報がないためです。
- 確認済み：AE 1.6.1170、XPMSE、OStim Standalone 7.5.1b。未確認：SE 1.5.97、Skyrim 1.7.x、XPMSE以外のスケルトン、クリーチャーのシーン。VRには対応していません。

## 制限

- 腕を伸ばしきっても届かない場合は、伸ばしきった位置で止まります。指の形はアニメのままです。
- 複数のルールが食い違うときは、重みに応じた妥協点になります。
- OStimのアライメントメニューで、同じ身長の組み合わせ用に手動調整済みのシーンでは、補正が二重にかかります。
  その手動調整をリセットするか、`fStrength` を下げてください。
- 身長はスケルトン全体の大きさから求めています。Mu Skeleton Editor などで、全体の大きさはそのままで足だけ長くするような比率の変更は、身長差として扱われないため、ずれが残ることがあります。
